0. Quick Start Guide: Build Your First Plugin

You do not need to install complex build tools or write Qt GUI code[cite: 2, 3]. Let us write a working plugin starting with literally one single line of Python code[cite: 2, 3].

Step 1: Where to save your file

Create a new text file named my_tool.py and save it in the my_plugins folder next to your application executable[cite: 2]:

AstroBasics/
		  ├── AstroBasics.exe
		  └── my_plugins/
		        └── my_tool.py   <-- Save your file here

Step 2: The absolute simplest 1-line plugin

Open my_tool.py and type this single line[cite: 2, 3]:

def render(ui, chart): ui.text("Hello World!")

Save the file and switch to AstroBasics. Your plugin will appear in the sidebar with the text "Hello World!"[cite: 2, 3].

Step 3: Expanding line by line

Now let us expand it line-by-line so you understand exactly what each line does[cite: 2, 3]:

# Line 1: Import the astrological engine library
		import astro_engine
		
		# Line 2: Name your plugin header box
		PLUGIN_NAME = "My Planet Inspector"
		
		# Line 3: Choose which sidebar group it belongs to (e.g. "Strengths", "Analysis Engine", "UTILS")
		PLUGIN_GROUP = "Analysis Engine"
		
		# Line 4: Set the priority number (lower numbers appear higher up in the list)
		PLUGIN_INDEX = 10
		
		# Line 5: Define the render function.
		# - 'ui' gives you easy methods to draw text, buttons, alerts, and tables.
		# - 'chart' gives you instant access to all planetary coordinates and houses.
		def render(ui: astro_engine.SimplePluginUI, chart: astro_engine.ChartContext):
		    
		    # Line 6: Add a heading to your plugin box
		    ui.heading("Live Sun Position", level=2)
		    
		    # Line 7: Read the Sun's occupied zodiac sign and formatted degree
		    sun_sign = chart.sun.sign_name
		    sun_degree = chart.sun.dms_str
		    
		    # Line 8: Display the information as a clean analytical card
		    ui.metric("Sun Placement", sun_degree, subtext=f"Placed in {sun_sign}")
		    
		    # Line 9: Add a conditional alert based on real astronomical data
		    if chart.sun.is_exalted:
		        ui.alert("The Sun is currently Exalted in Aries!", level="success")
		    elif chart.sun.is_debilitated:
		        ui.alert("The Sun is currently Debilitated in Libra.", level="warning")
		    else:
		        ui.alert(f"The Sun is in {sun_sign} in House {chart.sun.house}.", level="info")
		        
		    # Line 10: Add an interactive button that opens the Navamsha (D9) chart
		    ui.button("Open D9 Navamsha Chart", on_click=lambda current_chart: current_chart.spawn_window("D9", "Navamsha View"), variant="primary")
❖ Live Auto-Reloading: Keep the AstroBasics app running on your screen while you edit my_tool.py[cite: 2]. Every time you press Ctrl + S to save your script, the app refreshes your plugin within 500 milliseconds[cite: 2].

1. How to Discover All APIs (Even Unmentioned Ones)

You never have to guess what methods or properties exist on chart, planet, or ui. You can discover everything dynamically right from inside Python[cite: 3].

Method A: Print all available methods to the terminal

Add a temporary print() statement inside your render function to inspect any object in your console[cite: 2, 3]:

def render(ui, chart):
		    # Print every available method on the chart context
		    print("--- CHART METHODS ---")
		    print(dir(chart))
		    
		    # Print every property on the Sun
		    print("--- PLANET PROPERTIES ---")
		    print(dir(chart.sun))
		    
		    # Print the raw Swiss Ephemeris data dictionary
		    print("--- RAW PLANET DATA ---")
		    print(chart.sun._data)

Method B: Display all methods live inside the software UI

If you are running the packaged executable without a terminal, you can render all available properties into a scrollable table directly inside the application interface[cite: 2, 3]:

def render(ui, chart):
		    ui.heading("API Explorer: chart.sun Properties", level=2)
		    
		    # Extract all public properties and their current live values
		    inspection_rows = []
		    for attribute_name in dir(chart.sun):
		        if not attribute_name.startswith("_"):  # Skip private Python internals
		            try:
		                attribute_value = str(getattr(chart.sun, attribute_name))
		                inspection_rows.append([attribute_name, attribute_value])
		            except Exception as error:
		                inspection_rows.append([attribute_name, f"Error: {error}"])
		                
		    ui.table(headers=["Property Name", "Live Value"], rows=inspection_rows)

2. Plugin Architecture & Lifecycle

AstroBasics Diamond Chart Pro features an embedded dynamic Python runtime. Scripts dropped into either plugin directory are automatically compiled, mounted into the sidebar, and integrated into the host event loop without application restarts.

Directory Type Location Description
User Plugins ./my_plugins/ Primary path for custom user extensions. Created next to the executable on startup.
Core Modules ./dynamic_settings_modules/ System package folder for baked-in modular application tools.
❖ Hot-Reloading & File Watchers: Both folders are monitored via QFileSystemWatcher. Modifying any .py file automatically reloads and refreshes the UI within 500 milliseconds. An immediate hard reload can also be triggered via the 🔄 button in the top-right corner of the menu bar.

4. The 5 Plugin Authoring Paradigms

AstroBasics inspects your Python script upon discovery and mounts it using whichever pattern you implement[cite: 2]:

Paradigm 1: Declarative UI Builder via def render(ui, chart)

The standard, recommended hook for interactive panels[cite: 2]. The host provides a SimplePluginUI builder and the current ChartContext[cite: 2]. When time steps or chart parameters change, the container is cleared and render runs automatically[cite: 2]:

import astro_engine
			
			PLUGIN_NAME = "Dignity & Placement Matrix"
			PLUGIN_GROUP = "Strengths"
			PLUGIN_INDEX = 15
			
			def render(ui: astro_engine.SimplePluginUI, chart: astro_engine.ChartContext):
			    ui.heading("Planetary Dignity Summary", level=2)
			    
			    # 1. Analytical Metric Badges
			    exalted_planets = [planet.name for planet in chart.planets.values() if planet.is_exalted]
			    debilitated_planets = [planet.name for planet in chart.planets.values() if planet.is_debilitated]
			    
			    ui.metric("Exalted Planets", len(exalted_planets), subtext=", ".join(exalted_planets) if exalted_planets else "None", color="#16A34A")
			    ui.metric("Debilitated Planets", len(debilitated_planets), subtext=", ".join(debilitated_planets) if debilitated_planets else "None", color="#DC2626")
			    
			    # 2. Status Alert Banner
			    if chart.sun.is_combust:
			        ui.alert(f"Warning: Sun is in close orb ({chart.sun.dms_str}) causing combustion.", level="warning")
			    else:
			        ui.alert("Solar combustion levels: Normal", level="success")
			        
			    # 3. Interactive Data Table
			    table_rows = []
			    for planet in chart.planets.values():
			        table_rows.append([planet.name, planet.sign_name, planet.dms_str, f"House {planet.house}"])
			        
			    ui.table(headers=["Planet", "Sign", "Position", "Bhava"], rows=table_rows)
			    
			    # 4. Embedded Live Visual Chart
			    ui.separator()
			    ui.chart(div="D9", box_size=220)
			    ui.button("Open Full D9 Modal", on_click=lambda active_chart: active_chart.spawn_window("D9", "Navamsha View"), variant="primary")

Paradigm 2: Declarative AstroPlugin Decorators

Zero-boilerplate pattern for automated diagnostics, condition badges, and action buttons:

import astro_engine

PLUGIN_NAME = "Yoga Engine Pro"
PLUGIN_GROUP = "Analysis Engine"
PLUGIN_INDEX = 20

plugin = astro_engine.AstroPlugin(PLUGIN_NAME, group=PLUGIN_GROUP, index=PLUGIN_INDEX)

@plugin.rule("Gajakesari Yoga")
def check_gajakesari(chart: astro_engine.ChartContext):
    if chart.jupiter.is_in_kendra_to(chart.moon):
        return f"Jupiter is {chart.jupiter.house_from(chart.moon)} houses away from Moon."
    return False

@plugin.action("Inspect Career (D10)", variant="primary")
def launch_d10(chart: astro_engine.ChartContext):
    chart.spawn_window(div="D10", title="D10 Dashamsha Career Chart")

Paradigm 3: Pure Functional Hook via def evaluate(chart)

Ideal for calculations, diagnostic reports, and data formatting without UI code:

PLUGIN_NAME = "Diagnostic Reporter"
PLUGIN_GROUP = "Analysis Engine"

def evaluate(chart: astro_engine.ChartContext) -> dict:
    return {
        "Atmakaraka (AK)": f"{chart.ak.name} ({chart.ak.dms_str} in {chart.ak.sign_name})",
        "Lagna Lord": f"{chart.house_lord(1).name} placed in House {chart.house_lord(1).house}",
        "Active Dasha Sequence": " -> ".join(chart.get_dasha_sequence())
    }

Paradigm 4: Polymorphic & Native PyQt6 (def setup_ui)

Supports signature introspection. If defined as setup_ui(ui, chart), it functions as a declarative builder. If defined as setup_ui(app, layout), you receive direct access to PyQt6 widgets: 

from PyQt6.QtWidgets import QPushButton, QLabel, QVBoxLayout
import astro_engine

PLUGIN_NAME = "Native Qt Control"

def setup_ui(app, layout: QVBoxLayout):
    lbl = QLabel("Native PyQt6 Controller Active")
    btn = QPushButton("Calculate Panchang")
    btn.clicked.connect(lambda: lbl.setText(str(astro_engine.get_active_chart("D1").get_panchang())))
    layout.addWidget(lbl)
    layout.addWidget(btn)

Paradigm 5: Menu Bar Integration (def setup_menu)

When plugins are placed in the top menu bar via Manage Layout, this hook populates menu actions:

from PyQt6.QtGui import QAction
import astro_engine

def setup_menu(app, parent_menu):
    act = QAction("Launch D9 Navamsha Window", app)
    act.triggered.connect(lambda: astro_engine.get_active_chart("D1").spawn_window("D9", "Navamsha"))
    parent_menu.addAction(act)

5. ChartContext API Reference

The ChartContext object provides access to all chart data:

Direct Planetary Accessors

Access celestial bodies as typed PlanetProxy objects:

chart.sun, chart.moon, chart.mars, chart.mercury, chart.jupiter, chart.venus, chart.saturn, chart.rahu, chart.ketu, chart.ascendant (or chart.lagna).

Jaimini Karakas (7-Karaka System)

chart.atmakaraka (chart.ak), chart.amatyakaraka (chart.amk), chart.bhratrikaraka (chart.bk), chart.matrikaraka (chart.mk), chart.putrakaraka (chart.pk), chart.gnatikaraka (chart.gk), chart.darakaraka (chart.dk).

Analytical Methods

  • chart.occupants(house_num): Returns list of PlanetProxy in house (1–12).
  • chart.house_lord(house_num): Returns ruling PlanetProxy of that house.
  • chart.dispositor_of(planet_name): Returns sign dispositor of target planet.
  • chart.is_conjunct("Mars", "Saturn"): Returns boolean check.
  • chart.has_parivartana("Sun", "Mars"): Checks mutual sign exchange.
  • chart.is_aspecting_house("Mars", 8): Evaluates aspects.
  • chart.distance_between("Sun", "Moon"): Shortest angular separation (0°–180°).
  • chart.get_dasha_sequence(): Returns active Vimshottari lords.
  • chart.get_panchang(): Returns dictionary of Tithi, Nakshatra, Sunrise, Sunset.
  • chart.get_divisional_chart("D9"): Computes isolated context for any division.

6. PlanetProxy & Degree Formatting

Every celestial body returned by chart.get_planet(...) or direct properties like chart.mars is a PlanetProxy object[cite: 3]:

Property Type Example / Description
planet.name / planet.sym str "Mars" / "Ma"[cite: 3]
planet.lon AstroDegree Absolute zodiac longitude (0.0° to 359.9999°)[cite: 3]
planet.degree / planet.deg_in_sign AstroDegree Degree within occupied sign (0.0° to 29.9999°)[cite: 3]
planet.dms / planet.dms_str tuple / str (14, 25, 36) / '14° 25\' 36"'[cite: 3]
planet.sign_num / planet.sign_name int / str 5 / "Leo" (1-indexed sign number)[cite: 3]
planet.house int Occupied house number (1–12)[cite: 3]
planet.is_exalted / planet.is_debilitated bool Classical Parashari exaltation/debilitation flags[cite: 3]
planet.is_retro / planet.is_combust bool Retrograde motion / Solar combustion checks[cite: 3]
planet.nakshatra / planet.nakshatra_pada str / int Nakshatra name and Pada number (1–4)[cite: 3]

7. SimplePluginUI Declarative Toolkit

The declarative UI builder creates responsive, theme-adaptive widgets without direct PyQt6 imports:

Method Parameters & Usage
ui.heading(text, level=2) Renders responsive section header (level 1, 2, or 3).
ui.text(text, bold, italic, color) Renders word-wrapped styled text block.
ui.alert(message, level) Status banner. Levels: "info", "success", "warning", "danger".
ui.metric(label, value, subtext, color) Renders high-visibility analytical KPI badge.
ui.progress_bar(label, value, max_val) Displays progress or degree completion bar.
ui.table(headers, rows) Structured scrollable data table with auto-translated columns.
ui.tabs(tab_dict) Multi-tab view mapping tab names to builder callbacks.
ui.button(label, on_click, variant) Button with callback. Variants: "default", "primary", "danger", "success".
ui.dropdown(label, options, on_select) Combobox select dropdown.
ui.input_number(label, min, max, default) Integer or decimal spinbox control.
ui.slider(label, min, max, default) Horizontal slider with live numeric readout.
ui.chart(div, box_size) Embeds a live North Indian Diamond Chart widget inside the panel.
ui.open_chart(div, title, modal) Spawns a pop-up chart dialog window.

8. Practical Code Examples

Example 1: Interactive Orb & Separation Meter (def render)

Save as ./my_plugins/orb_meter.py[cite: 2]:

import astro_engine
			
			PLUGIN_NAME = "Orb & Separation Inspector"
			PLUGIN_GROUP = "Analysis Engine"
			PLUGIN_INDEX = 25
			
			def render(ui: astro_engine.SimplePluginUI, chart: astro_engine.ChartContext):
			    ui.heading("Planetary Distance & Orb Meter", level=2)
			    
			    planet_names = ["Sun", "Moon", "Mars", "Mercury", "Jupiter", "Venus", "Saturn", "Rahu", "Ketu", "Ascendant"]
			    
			    planet1_selector = ui.dropdown("Reference Body:", planet_names, default="Sun")
			    planet2_selector = ui.dropdown("Target Body:", planet_names, default="Saturn")
			    
			    first_planet = chart.get_planet(planet1_selector.currentText())
			    second_planet = chart.get_planet(planet2_selector.currentText())
			    
			    if first_planet and second_planet:
			        angular_separation = first_planet.distance_to(second_planet)
			        forward_separation = first_planet.forward_distance_to(second_planet)
			        house_distance = first_planet.house_distance_to(second_planet)
			        
			        ui.metric("Shortest Angular Separation", angular_separation.dms_str, subtext=f"Absolute Arc: {float(angular_separation):.4f}°", color="#D97706")
			        ui.metric("Zodiac House Count", f"{house_distance} Houses Away", subtext=f"Forward Distance: {float(forward_separation):.2f}°", color="#2563EB")
			        
			        if angular_separation <= 3.0:
			            ui.alert("Critical Conjunction / Aspect: Exact Orb (< 3°00')", level="danger")
			        elif angular_separation <= 8.0:
			            ui.alert("Close Influence: Active Orb (< 8°00')", level="warning")
			        else:
			            ui.alert("Wide Separation: Outside immediate influence orbs.", level="info")
			
			    ui.separator()
			    ui.button("Check Mutual Relationship", on_click=lambda active_chart: inspect_relationship(ui, first_planet, second_planet), variant="primary")
			
			def inspect_relationship(ui: astro_engine.SimplePluginUI, first_planet: astro_engine.PlanetProxy, second_planet: astro_engine.PlanetProxy):
			    if not first_planet or not second_planet:
			        return
			        
			    relationship_types = []
			    if first_planet.is_in_kendra_to(second_planet): relationship_types.append("Kendra (1/4/7/10)")
			    if first_planet.is_in_trine_to(second_planet):  relationship_types.append("Trikona (1/5/9)")
			    if first_planet.is_in_shadashtaka(second_planet): relationship_types.append("Shadashtaka (6/8)")
			    if first_planet.is_in_dwirdwadasa(second_planet): relationship_types.append("Dwirdwadasa (2/12)")
			    
			    relationship_summary = ", ".join(relationship_types) if relationship_types else "Neutral placement"
			    ui.notify(f"Relationship: {first_planet.name} ↔ {second_planet.name}", f"Placement Pattern: {relationship_summary}\n\n{first_planet.name}: {first_planet.formatted_degree}\n{second_planet.name}: {second_planet.formatted_degree}")

9. Development & Debugging Checklist

  • Hot-Reloading: Keep AstroBasics running while editing scripts in ./my_plugins/. Changes update within 500ms of saving.
  • Degree Precision: Use p.degree / p.deg_in_sign for 0°–30° sign positions and p.lon for 0°–360° absolute zodiac math.
  • String Output: Use p.dms_str (e.g. 14° 25' 36") for formatted text output.
  • Divisional Scope: Obtain isolated varga calculations via chart.get_divisional_chart("D9") to avoid mutating base D1 coordinates.
  • Localization: Pass plain English string literals into SimplePluginUI methods (e.g. ui.heading("Overview")); the runtime translation layer matches and translates them dynamically.
