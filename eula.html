4. Diagnostic Telemetry & Updates Policy

To verify installation integrity, deliver bug fixes, prevent distribution tampering, and diagnose deployment issues, the Software is configured by default to exchange minimal, non-personal diagnostic telemetry with the Developer's secure update endpoint (Google Apps Script infrastructure over HTTPS).

This operational data contains zero personally identifiable information (PII) and is strictly separated from your astrological files.

When Diagnostics Are Transmitted

  • Application Launch (ping): Notifies the release infrastructure that an active installation is alive.
  • Periodic Heartbeat (ping): Transmitted once every 5 minutes while the application is active in the foreground.
  • Update Checks & Installs (update_check / android_update): Transmitted when querying GitHub manifests for security and feature patches.
  • Application Shutdown (app_closed): Notifies the status registry when the app process is cleanly closed or sent to the background.

6. How to Opt Out of Telemetry

You have the absolute right to revoke telemetry transmissions at any time. Because presence telemetry is integrated with automated release checking, opting out turns off both background diagnostic pings and automated update checks:

Windows Desktop Opt-Out Steps

  1. Open AstroBasics Diamond Chart Pro on your PC.
  2. In the left sidebar, navigate to the Updater section (or click Updates in the top menu bar).
  3. Uncheck "Check for updates automatically on startup" (or uncheck "Auto-Check on Startup" in the menu).
  4. Confirm the prompt. This writes "auto_update": false to updater_config.json, immediately blocking all outbound telemetry network sockets.

Android Mobile Opt-Out Steps

  1. Open AstroBasics on your Android device.
  2. Open the navigation drawer (☰) and tap ⚙️ Open All Settings at the bottom.
  3. Switch to the ⚙️ App Settings tab.
  4. Under "Automatic Updates & Telemetry", tap the button to switch it from Enabled (✓) to Disabled (✕).
  5. Confirm the opt-out dialog. This sets astrobasics_telemetry_opt_out in persistent local storage, instantly halting all telemetry pings, heartbeats, and OTA requests.

7. Third-Party Services & Network Calls

The Software operates virtually 100% offline, opening outbound network sockets strictly for:

  • Location Search (Geocoding): When you type a city name (e.g. "Varanasi") and press Search, only the entered city name string is sent to the public OpenStreetMap (Nominatim) API to retrieve latitude, longitude, and timezone coordinates. No chart or birth data is ever attached.
  • Cryptographic Release Manifests: Secure update checks query GitHub over HTTPS to verify digitally signed Ed25519 manifests before downloading any package.
  • Optional Community Polls: When you voluntarily submit a vote on upcoming software features, only your selected option index is transmitted.
