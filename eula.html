5. Functional Network Operations & Third-Party APIs

To provide optional conveniences, the Software interfaces with specific third-party network endpoints exclusively on-demand under the following transparent conditions:

  • Geographic Location Geocoding: When the User types a city or location name and triggers a search, the entered text query is transmitted exclusively to public geocoding services (such as OpenStreetMap Nominatim) to resolve corresponding latitude and longitude coordinates. No personal identity, birth timestamps, or natal chart data are transmitted with these queries.
  • Timezone Offset Resolution: To verify accurate local time offsets, coordinate pairs are transmitted to the Open-Meteo API (`api.open-meteo.com`). If an internet connection is unavailable or the request is bypassed, the Software falls back to an internal offline timezone lookup library (`tzfpy`) without initiating any network traffic.

Licensor makes no warranties regarding the continuous availability or absolute geographic accuracy of external third-party geocoding providers.

6. Cryptographic Update Integrity & Voluntary Community Polling

The Software incorporates secure routines to maintain distribution integrity, detect build regressions, and solicit community feature direction:

  • Cryptographic Release Manifests: When checking for updates, the Software queries a public static repository (e.g., GitHub) over HTTPS to compare version numbers and file hashes. Update manifests are verified against asymmetric digital signatures (Ed25519) and SHA-256 checksums to safeguard against tampering, man-in-the-middle attacks, and rollback attempts. No user profile information or personal chart records are transmitted during update checks.
  • Voluntary Community Feature Polling: Following application updates, the Software may present an optional community poll dialog regarding upcoming feature priorities. If and only if the User voluntarily submits a vote, the Software transmits exclusively the selected option index (`{"vote_index": integer}`) over HTTPS to an automated script endpoint. This submission contains no personally identifiable information (PII), names, email addresses, hardware identifiers, IP logs, or chart files.
